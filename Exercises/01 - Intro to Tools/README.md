# 00 - Intro to Tools

This tutorial should get you up and running with your Python environment, plus give you the basics of Jupyter notebooks.

- The [Setup and Python](./0.%20Setup%20and%20Python.ipynb) and [NumPy and PyTorch](./1.%20NumPy%20and%20PyTorch.ipynb) notebooks are walkthroughs of basic Python libraries that you have encountered before. Please use them as a smoke test to figure out if something needs a refreshement. They all show fundamental operations that we will use for real problems in the upcoming weeks. If you would like to solve exercises on these concepts please look online or follow the recommendations in [Additional Resources](../README.md).
- The [Handling Text](./2.%20Handling%20Text%20-%20Part%201.ipynb) include examples of classic NLP applications.
